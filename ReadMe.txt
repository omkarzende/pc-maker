# 🖥️ PC Maker

**Build your dream PC with ease**

An Android application that allows users to configure a custom PC by selecting compatible hardware components and viewing the total estimated cost.


---

# 📱 About the Project

PC Maker is an Android application developed to simplify the process of planning and building a custom desktop PC.

Instead of manually calculating prices and keeping track of different components, users can browse hardware categories, select their preferred parts, and generate a complete PC build with the estimated total cost.

The project was developed using Kotlin in Android Studio as part of an Android application development project.

---

# ✨ Features

- 🖥️ Browse PC hardware components
- ⚙️ Create a custom PC build
- 💰 Automatic total price calculation
- 📋 View complete build summary
- 📱 Clean Material Design interface
- ⚡ Lightweight and responsive
- 🔄 Easy navigation between screens
- 🎯 Beginner-friendly user experience

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/omkarzende/pc-maker.git
```

---

## Open in Android Studio

```
File
    ↓
Open
    ↓
Select the cloned project
```

---

## Run the Application

1. Sync Gradle.
2. Connect an Android device or launch an emulator.
3. Click **Run ▶️**.

---

# 📋 Requirements

- Android Studio Flamingo or newer
- Android SDK
- Gradle

---

# 📖 How It Works

1. Launch the application.
2. Browse available PC components.
3. Select your desired hardware.
4. Review your custom build.
5. View the estimated total price.
